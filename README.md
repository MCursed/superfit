# SuperFit

Responsive fitness website built with HTML, CSS, and JavaScript.

## Live Demo

https://mk-dev-frontend.github.io/superfit/

## Features

* Fully responsive layout (mobile, tablet, desktop)
* Multilingual support (UA / EN)
* Interactive image gallery with GLightbox
* Splide.js slider for gym showcase
* Mobile burger menu
* Sticky header with scroll effects
* Smooth anchor navigation
* Dynamic language switching via JavaScript
* Persistent language selection using LocalStorage

## Technologies Used

* HTML5
* CSS3 (Flexbox, Grid, Responsive Design)
* Vanilla JavaScript (ES6+)
* Splide.js
* GLightbox
* LocalStorage

## Description

This project was built as a frontend practice project. The main focus was creating a responsive user interface and implementing interactive functionality using pure HTML, CSS, and JavaScript without frameworks.

The website adapts to different screen sizes and includes a multilingual system based on JavaScript and LocalStorage, allowing users to switch languages without reloading the page and keeping their preference saved.

## Notes

* Built without frameworks (pure HTML, CSS, and JavaScript)
* Integrated third-party libraries (Splide.js and GLightbox)
* Responsive and cross-browser compatible
* Optimized for desktop and mobile devices
* All images used in the project were AI-generated
